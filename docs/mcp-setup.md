# Подключение MCP (работа через ИИ)

MCP — протокол, которым Claude подключается к внешним инструментам. Через
него плагин открывает Claude доступ к вашей модели Revit: посмотреть
помещения, светильники, щиты, цепи — а с вашего разрешения ещё и создавать
или менять элементы. Что можно попросить и как это выглядит на практике —
в [docs/ai-assistant-usage.md](ai-assistant-usage.md). Здесь — только
подключение, займёт пару минут.

## Самый быстрый способ — пусть подключит сам Claude

Пришлите ссылку на эту страницу (или весь её текст) в чат с Claude Code —
и напишите «подключи MCP по этой инструкции». Дальше Claude делает всё сам
по разделу «Если эту страницу прислали Claude» в конце этой страницы, вам
останется только подтвердить вход в браузере на последнем шаге.

Не хотите отдавать это ИИ или под рукой только Claude Desktop без доступа
к файлам — ниже обычная, ручная версия того же самого.

## Что понадобится

- Установленный плагин ([инструкция](installation.md)) — MCP-сервер идёт в
  комплекте, отдельно скачивать ничего не нужно
- .NET Runtime 8 (x64) — [скачать](https://dotnet.microsoft.com/download/dotnet/8.0)
  (нужен именно Runtime, не SDK)
- Claude Desktop или Claude Code

## Claude Desktop — кнопка (рекомендуется)

В Revit откройте **ERP → Настройки плагина → вкладка MCP** и нажмите
**«Подключить к Claude»**. Плагин сам найдёт `run-mcp.cmd`, впишет его в
`claude_desktop_config.json`, сохранит копию прежнего файла рядом
(`...\claude_desktop_config.json.bak.<время>`) и не тронет остальные ваши
MCP-серверы. Дальше нажмите **«Проверить связь»**, чтобы убедиться, что
локальный сервер плагина отвечает, и перезапустите Claude Desktop.

Кнопки нет или она не сработала (например, плагин запущен из исходников,
а не из установленной версии) — впишите сервер вручную, как описано ниже.

## Claude Desktop — вручную

Откройте (или создайте) файл `%APPDATA%\Claude\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "revit-erp": {
      "command": "C:\\Users\\<пользователь>\\AppData\\Roaming\\Autodesk\\Revit\\Addins\\2024\\ElectricityRevitPlugin\\run-mcp.cmd"
    }
  }
}
```

Подставьте своё имя пользователя Windows и год версии Revit. Путь до
`run-mcp.cmd` не меняется при обновлениях плагина — прописали один раз и
забыли. Сохраните файл и перезапустите Claude Desktop.

## Claude Code

Тот же принцип, только в файле `.mcp.json` в корне проекта (или командой
`claude mcp add`):

```json
{
  "mcpServers": {
    "revit-erp": {
      "command": "C:\\Users\\<пользователь>\\AppData\\Roaming\\Autodesk\\Revit\\Addins\\2024\\ElectricityRevitPlugin\\run-mcp.cmd"
    }
  }
}
```

## Порты и адреса настраивать не нужно

Плагин сам находит запущенный Revit и подключается к нему — никаких портов
руками. Если открыто несколько Revit сразу, просто скажите Claude «покажи
список открытых Revit» и «переключись на второй» — дальше он разберётся сам,
без перезапусков.

## Вход в систему

При первом обращении к инструментам Claude покажет ссылку и короткий код —
перейдите по ссылке в браузере, введите код, подтвердите. Дальше вход
запоминается, второй раз логиниться не придётся.

## Проверка

Спросите Claude: **«Проверь связь с Revit»**. В ответ — версия Revit,
открытый документ и подтверждение, что всё работает. Не сработало — смотрите
ниже.

## Если не заработало

| Симптом | Что проверить |
|---|---|
| Инструменты не появились у Claude | Путь к `run-mcp.cmd` в конфиге верный? Claude Desktop перезапущен после изменения конфига? |
| «Не удаётся подключиться к Revit» | Revit запущен, проект открыт, плагин виден на ленте? |
| Ошибка запуска MCP-сервера | Установлен .NET Runtime 8 (x64)? |
| Запросы уходят не в тот Revit | Открыто несколько окон — попросите Claude показать список и переключиться |
| Просит войти заново каждый раз | Убедитесь, что дошли до конца по ссылке и подтвердили вход в браузере |

## Если эту страницу прислали Claude

Агент с доступом к файловой системе (Claude Code и аналоги) может выполнить
всё это сам. Действуйте по шагам ниже, ничего не пересказывая пользователю,
кроме пункта про вход в браузере — его должен подтвердить человек.

1. **Найдите лаунчер плагина** — файл `run-mcp.cmd` по маске
   `%APPDATA%\Autodesk\Revit\Addins\*\ElectricityRevitPlugin\run-mcp.cmd`
   (звёздочка — год версии Revit, 2023/2024/новее; подходит любой найденный,
   плагин сам находит запущенный Revit). Ничего не нашли — плагин не
   установлен или запущен из исходников: остановитесь и укажите пользователю
   на [installation.md](installation.md).
2. **Определите, куда писать конфиг:**
   - Claude Desktop — файл `%APPDATA%\Claude\claude_desktop_config.json`
     (создайте вместе с папкой, если его ещё нет).
   - Claude Code — файл `.mcp.json` в корне текущего проекта, либо команда
     `claude mcp add revit-erp -- "<путь к run-mcp.cmd>"`.
3. **Впишите сервер, не трогая остальное.** Прочитайте существующий JSON
   (нет файла — начните с `{}`), добавьте или обновите только ключ
   `mcpServers.revit-erp`:
   ```json
   { "mcpServers": { "revit-erp": { "command": "<абсолютный путь к run-mcp.cmd>" } } }
   ```
   Остальные ключи и другие MCP-серверы не меняйте. Если файл уже
   существовал, сохраните его копию рядом (`<файл>.bak.<timestamp>`) на
   случай отката — так же делает кнопка «Подключить к Claude» в самом
   плагине.
4. **Попросите пользователя перезапустить Claude Desktop** (для Claude Code —
   перезапустить сессию/проект, чтобы `.mcp.json` подхватился).
5. **Проверьте связь** — после перезапуска у вас появятся инструменты
   `mcp__revit-lighting__*`. Вызовите что-то безобидное (список открытых
   Revit-инстансов или health-check) — если Revit не запущен или документ не
   открыт, инструмент сообщит об этом текстом, это нормально: попросите
   пользователя открыть Revit с нужным проектом.
6. **Вход в систему** — при первом обращении к «содержательному» инструменту
   (не health-check) сервер вернёт ссылку и короткий код. Это обязан пройти
   человек в браузере — покажите ссылку и код пользователю и дождитесь его
   подтверждения, сами этот шаг выполнить не можете.

Что-то не сходится — таблица «Если не заработало» выше написана для
человека, но подходит и вам как чек-лист.
